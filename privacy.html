Politica de Privacidad

Ultima actualizacion: Junio 2026

1. Informacion General

En NEXUS ("la Aplicacion", "nosotros"), respetamos tu privacidad. Esta Politica describe que datos recopilamos, como los usamos y como los protegemos.

2. Datos que Recopilamos

NEXUS opera principalmente de forma local en tu equipo. Los datos que recopilamos y procesamos incluyen:

  • Datos del juego: Informacion de tu cuenta de League of Legends obtenida a traves de la API local del cliente (LCU) y la API de Riot Games, incluyendo nombre de invocador, nivel, ligas, maestrias de campeones, historial de partidas y estadisticas de juego.
  • Datos de configuracion: Preferencias de usuario como configuracion de pantalla, frecuencias de actualizacion y ajustes de la interfaz.
  • Datos de uso local: Estadisticas de uso de la aplicacion almacenadas exclusivamente en tu equipo.

3. Como Usamos los Datos

Todos los datos se utilizan exclusivamente para proporcionar las funcionalidades de la Aplicacion:

  • Generar recomendaciones de campeones, runas, hechizos e items
  • Mostrar estadisticas y analisis de rendimiento
  • Personalizar la experiencia de coaching
  • Guardar tu historial de drafts y partidas
  • Mejorar los algoritmos de recomendacion

4. Almacenamiento de Datos

NEXUS almacena datos localmente en tu equipo (configuracion de usuario en config.json en %APPDATA%\LoLRecommender). Ademas, para acelerar la carga de estadisticas, los datos de partidas, drafts y perfil se cachean en una base de datos PostgreSQL compartida. No se almacenan datos personales ni credenciales en la nube.

5. Datos de la API de Riot Games

NEXUS utiliza la API de Riot Games de acuerdo con las politicas de desarrollador de Riot Games. Los datos obtenidos a traves de esta API se procesan localmente y no se comparten, venden ni distribuyen a terceros.

6. Terceros

No compartimos datos personales con terceros. Las unicas conexiones externas de la Aplicacion son:

  • API de Riot Games (para obtener datos del juego)
  • Data Dragon de Riot (para descargar iconos y assets del juego)
  • Base de datos PostgreSQL compartida en Render (cache de partidas y drafts)
  • GitHub Releases API (para verificar actualizaciones de la aplicacion)
  • Discord RPC (opcional, solo si el usuario tiene Discord abierto)

7. Seguridad

La Aplicacion no recopila ni transmite credenciales de inicio de sesion de Riot Games. Las llamadas a la API de Riot Games se realizan utilizando tokens de sesion locales generados por el cliente de League of Legends, que nunca abandonan tu equipo.

8. API Key

La clave de API de Riot Games proporcionada por el usuario se almacena localmente en un archivo de configuracion. No enviamos tu API key a ningun servidor externo.

9. Cambios a esta Politica

Podemos actualizar esta Politica de Privacidad ocasionalmente. Te notificaremos los cambios publicando la nueva version en esta pagina.
