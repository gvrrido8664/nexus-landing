Como funciona

NEXUS se conecta al cliente de LoL y te da recomendaciones en tiempo real. Asi es el flujo completo.

1

Ejecuta NEXUS

Al abrir la aplicacion, detecta automaticamente si tenes League of Legends instalado. Descarga los ultimos datos del parche via Data Dragon y carga el modelo de Machine Learning para el simulador 1v1.

  • Setup wizard automatico en el primer arranque
  • Datos actualizados cada parche (auto-update)
  • Sin configuracion manual necesaria
2

Entra a Champ Select

NEXUS detecta cuando entras a la seleccion de campeones y activa el Radar en Vivo automaticamente. Ves en tiempo real:

  • Counters y sinergias para tu campeon
  • Runas optimas con shards adaptativos
  • Hechizos de invocador recomendados
  • Bans sugeridos por linea
  • Winrate estimado del equipo 5v5
3

Importa o juega

Con un solo click, NEXUS puede importar runas, hechizos, orden de habilidades y sets de objetos directamente al cliente de LoL. Respetando tu tecla de Flash preferida.

  • Importacion automatica de paginas de runas
  • Seleccion de hechizos (respeta D/F)
  • Orden de habilidades Q>W>E>R
  • Set de objetos con core build y early game
4

Mejora y aprende

Despues de cada partida, NEXUS analiza tu rendimiento y te da coaching personalizado basado en tus estadisticas reales.

  • Reporte de habitos y champion pool
  • Ejercicios de practica deliberada
  • Analisis de fatiga y estado mental
  • Historial completo de drafts
  • Overlay en partida con KDA/CS en vivo

Tu privacidad es primero

NEXUS funciona localmente. No compartimos tus datos con nadie.

🔒

Tu API key esta segura

La clave de API se guarda localmente en config.json, fuera del ejecutable. NEXUS nunca envia tu API key a servidores externos.

☁️

Datos en la nube (compartidos)

Tu historial de partidas, drafts y datos de perfil se almacenan en una base de datos PostgreSQL compartida para habilitar el cacheo rapido. No se almacenan datos personales ni credenciales.

🚫

No modifica el juego

NEXUS no altera el cliente de LoL, no inyecta codigo ni automatiza acciones de juego. Solo consulta datos de la API local (LCU) y la API de Riot.

📄

Cumple con las politicas de Riot

Usamos exclusivamente los endpoints documentados de la API de Riot Games y la LCU. No hacemos scraping ni usamos datos de fuentes no oficiales.
